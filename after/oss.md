## How to contribute (repeatable)

1. Read README + CONTRIBUTING + LICENSE
2. Clone → run the documented quickstart
3. Find `good first issue` or a docs typo
4. Comment only if you will work on it
5. Small PR — docs/tests welcome
6. Use Claude to understand code; Cursor to implement; **you** write the PR text

**Do not:** mass-open AI-generated PRs. Maintainers will close them and remember the username.

---

## Writing that counts as contribution

- Fix a broken link or unclear setup step
- Add an example to docs
- Improve an error message (if the project wants that)
- Write a clear issue: steps, expected, actual

See [follow-up.md](follow-up.md).
