# Weekly Challenges (All Tracks)

Copy this checklist to your notes app. Pair with [follow-up.md](follow-up.md) for reading and writing.

---

## Week 1 — Polish mini-project

**Everyone:**

- [ ] README: problem, setup, screenshot or curl example
- [ ] Clean Git history (3+ meaningful commits)
- [ ] Remove secrets, add `.env.example`
- [ ] Start `LEARNING.md` (template in follow-up.md)
- [ ] Write 5 sentences: "What I learned without AI vs with AI"

**AI task:** Claude — "Review my README as a recruiter. What's missing?"

---

## Week 2 — Track foundations

Complete **Module 1 + 2** in your track doc.

- [ ] Update `ARCHITECTURE.md` — diagram + trade-offs
- [ ] `LEARNING.md` Week 2 + 10 bullet takeaways from **one** reading
- [ ] One new feature **or** one OSS CONTRIBUTING.md read + issue URL saved

**AI task:** Claude design review → Cursor implement Module 2

---

## Week 3 — Solo mini project **or** writing

Build something **new** in 3–5 hours **or** ship a public writing piece plus an OSS comment.

| Track | Suggested project |
|-------|-------------------|
| Full-stack | SQLite persistence + UI polish |
| Automation | Auto-backup script, file organizer, CSV pipeline |
| AppSec | Scan 3 of **your** repos; write a findings note |
| AI Product | Q&A over your course notes (keyword RAG) |

- [ ] Public repo **or** LinkedIn/blog link
- [ ] 2-min screen recording **or** demo to a friend

**AI task:** Claude first — 1-page PRD, then Cursor build — **or** draft + you rewrite the article

---

## Week 4 — Scaffold

You don't need a final hackathon theme yet.

- [ ] Create `hackathon-ideas.md` with 3 problem statements
- [ ] Pick top 1 — validate with 2 classmates
- [ ] Scaffold repo: README, folder structure, empty endpoints
- [ ] Mermaid architecture (AI-generated, **you** edited)
- [ ] One OSS action: issue comment, docs PR, or first-contributions

**Prompt:**

```
Problem: [yours]
Stack: Python FastAPI, ...
Generate a README: problem, users, MVP scope for 1 week, non-goals
I will edit this.
```

---

## Optional stretch (any week)

- [ ] One OSS issue commented or PR opened (docs/tests preferred)
- [ ] LinkedIn post: "What I built with AI tools this week"
- [ ] Teach one concept to a junior student

---

## If you fall behind

**Minimum viable month:**

1. Mini-project repo polished (Week 1)
2. One track module + LEARNING.md (Week 2)
3. Skip Week 3 project → extend mini-project **or** write 200 words
4. Week 4 idea doc only

Showing **one good repo** plus **honest notes** beats three abandoned ones.
